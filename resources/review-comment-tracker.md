## Status definitions

- **Pending:** Not yet reviewed.
- **Understood:** Request and expected behavior are clear.
- **In progress:** Implementation or investigation has started.
- **Addressed:** A code change or explanation is complete.
- **Needs clarification:** Request is ambiguous, incomplete, or conflicting.
- **Not applicable:** Reason has been documented and communicated.
- **Verified:** The fix and response have been checked.

## Review pass checklist

- [ ] Correct repository and pull request confirmed.
- [ ] All review threads collected.
- [ ] Issue comments separated from review requests.
- [ ] Duplicate comments grouped.
- [ ] Conflicting feedback identified.
- [ ] Clarifications requested where required.
- [ ] Implementation plan reviewed.
- [ ] Each fix has a verification method.
- [ ] Tests and final diff reviewed.
- [ ] Each response links to the relevant change or explanation.
- [ ] Only verified threads were resolved.
